# 🌐 Swara Setu AI

**Live Demo:** [Click here to try Swara Setu AI](https://swarasetuai.streamlit.app/)

**Swara Setu AI** is a real-time, two-way voice translation web application designed to break down language barriers. Built with Python and Streamlit, it provides seamless spoken communication across 26+ global languages, making it a highly practical tool for travel, business, and everyday conversations.

## ✨ Key Features
* **Real-Time Speech-to-Speech:** Instantly transcribes spoken audio, translates it, and speaks the output out loud.
* **Two-Way Conversation Bridge:** A dedicated "Swap" mechanism instantly reverses the input and output languages for natural, back-and-forth communication.
* **Global Support:** Supports over 26 major languages including Telugu, Hindi, English, Spanish, Japanese, and Arabic.
* **Professional UI/UX:** A clean, modern, and highly responsive interface designed for immediate accessibility.

## 🛠️ Tech Stack
* **Frontend:** Streamlit, Custom CSS
* **Backend:** Python
* **Audio Processing:** SpeechRecognition, gTTS (Google Text-to-Speech)
* **Translation API:** Google Translate API
* **Deployment:** Streamlit Cloud
